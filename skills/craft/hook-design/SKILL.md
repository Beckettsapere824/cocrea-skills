# 钩子设计：3 秒内让人停下，且不透支信任

## 目标

给用户一套可操作的方法,设计标题/开头/封面的钩子——在读者划走之前的 3 秒内给出停留理由,同时**守住一条底线:钩子是个真实的承诺,内容必须兑现它**。

## 立场 (Stance)

钩子负责「点进来」,内容负责「留下来」。两者必须是同一个承诺。

- **钩子的本质是承诺**:你在开头许诺读者「读下去会得到 X」。好钩子让承诺**具体、有张力、与读者有关**。
- **标题党的本质是违约**:承诺 X 却给了 Y。它能骗到一次点击,但代价是信任——读者下次见到你直接划走,平台也会因低完播惩罚你。**骗来的点击用信任偿还,利息很高。**
- **判断尺**:写完钩子问自己「我的内容真的兑现了这个承诺吗?」兑现 → 好钩子;没兑现 → 标题党,改内容或改钩子。

## 使用流程

1. **定承诺**:先想清楚「读者读完能得到的最具体的一件事」是什么——这是钩子要许诺的。
2. **制造张力**(三选一,别贪多):
   - **信息差**:「90% 的人都搞错了 X」(你确实要揭示那个错)
   - **具体结果**:「我用 3 天把 X 从 0 做到 Y」(数字具体、可信)
   - **痛点共鸣**:「如果你也卡在 X……」(精准戳中目标读者的处境)
3. **降认知成本**:钩子本身要 3 秒读懂,别用行话/绕弯。
4. **兑现检查**(关键):对照内容,确认承诺被真实兑现。没兑现就回去改——**改内容,不是改成更夸张的钩子**。
5. **A/B 心态**:钩子是可迭代的,产出 2-3 个版本,用数据(点击率/完播)选,而不是凭感觉。

## 输出格式

```
【这条内容的核心承诺】读者读完能得到的最具体一件事：……
【钩子版本 A（信息差/结果/共鸣 选一）】……
【钩子版本 B】……
【兑现检查】内容是否真的兑现了承诺？✓/✗（✗ 则改内容）
【认知成本】钩子能否 3 秒读懂？✓/✗
```

## 示例

Input:「我做了个教人用 Excel 的视频,标题叫『Excel 教程第 12 集』,没人点。」
Output:
- 核心承诺(原标题完全没给):看完能省下手动整理数据的时间。
- 钩子 A(结果):「这个 Excel 操作,帮我把 2 小时的报表做成了 5 分钟」
- 钩子 B(信息差):「99% 的人还在手动做的这步,其实一个快捷键就够了」
- 兑现检查:视频里确实教了那个操作 → ✓,不是标题党。
- 认知成本:✓,3 秒读懂且有具体回报。原标题「第 12 集」给了零承诺,等于没钩子。
