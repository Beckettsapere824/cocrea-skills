# 费曼技巧:讲不清,就是没真懂

## 目标

给用户一套可操作的方法,用「把概念讲给外行听」来**暴露并填补理解的漏洞**——讲到卡壳或必须用术语糊弄的地方,就是你没真懂的地方。

## 立场 (Stance)

「看懂了」是最危险的学习幻觉。读一遍觉得「嗯有道理」,和能从头讲清楚、能应对追问,是**完全不同**的两种状态。前者是**识别**(看到答案能认出来),后者才是**生成**(能自己产出)。

- **费曼技巧的本质**:用「输出」倒逼「输入」。能用大白话讲清楚,说明你真的重构了知识;讲不清,说明你只是面熟。
- **关键纪律——禁止术语遁逃**:卡壳时人会本能地用专业术语「我就是这么背的」糊过去。这恰恰是漏洞所在。规则:讲解时假装对面是个聪明的初中生,不许用没解释过的术语。
- **边界**:费曼技巧检验「理解类」知识极有效;对纯记忆类(如不讲道理的事实、外语单词)效果有限,那类该用 active-recall / 间隔重复。

## 使用流程

1. **选概念**:让用户挑一个他「以为懂了」的概念。
2. **讲给外行**:让他用大白话讲一遍,假设听众是聪明但零基础的初中生——AI 扮演这个初中生,听不懂就追问。
3. **标记卡壳**:记录他讲到哪里卡住、哪里必须用术语糊弄、哪里自己都觉得心虚——这些是真实的理解漏洞。
4. **回去补漏**:针对卡壳处回到材料重新学,只补这些漏,而不是重读全部。
5. **再讲一遍**:重讲,直到能顺畅讲完、能应对「为什么」的追问。
6. **用类比固化**:能给出一个贴切的生活类比,是真懂的标志(类比错了也暴露理解偏差)。

## 输出格式

```
【要检验的概念】……
【用大白话讲一遍】（用户输出，AI 扮演初中生追问）
【卡壳/术语遁逃的地方】= 你的理解漏洞：……
【该回去补的（只补漏，不重读全部）】……
【一个生活类比】（讲得出 = 真懂）……
```

## 示例

Input:「我复习『机会成本』,书上定义我能背,但做题总错,不知道哪没懂。」
Output:
- 概念:机会成本。
- 讲一遍:让用户脱稿用大白话讲给「初中生」。他可能讲到「就是放弃的成本」就卡住——AI 追问:「放弃的哪个?我放弃了好多东西啊?」
- 卡壳处:他答不清「是放弃的**所有**选项还是**最好的那一个**」——这就是漏洞,也正是做题出错的根源。
- 补漏:只回去搞清「机会成本 = 放弃的**最优**替代选项,不是所有放弃项之和」。
- 再讲 + 类比:「我用周末时间打工赚 200,机会成本不是『没出去玩+没睡觉+没学习』全加起来,而是这段时间我能做的**最有价值**的那一件事。」讲得出这个类比 = 真懂了。
