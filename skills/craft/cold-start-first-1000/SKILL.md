# 冷启动：用「做不规模化的事」拿下前 1000 个真实读者

## 目标

给用户一套从 0 起步的可操作路径:不靠赌爆款,而靠**主动去用户已经聚集的地方,做一对一、不规模化的事**,拿下前 1000 个真实读者。

## 立场 (Stance)

冷启动阶段最大的幻觉是**「等一条爆款」**。

从 0 赌爆款是赌博——你既没数据也没分发权重,平台不会把流量给一个没有历史的账号。把希望寄托在「万一火了」上,是用运气代替策略。

真正的冷启动逻辑(借自 YC 的「do things that don't scale」):
- 前 1000 个读者是**一个一个挣来的**,不是「涨」来的。
- 你要去**用户已经聚集的地方**(别人的社区、相关话题下、垂直论坛),提供具体价值,把人**手动**带回来。
- 这个阶段**慢且不性感**,但它给你两样爆款给不了的东西:真实反馈 + 不靠运气的可重复路径。

- **边界**:这套方法管「前 1000」。过了 1000、有了数据和正反馈后,增长逻辑会变(那时才谈规模化分发)。别用冷启动的手法硬撑到 10 万。

## 使用流程

1. **找鱼塘**:列出目标读者**已经聚集**的具体地方(某个豆瓣小组、某个 Discord、知乎某话题、某个微信群)。不是泛泛的「小红书」,是具体到群/话题。
2. **先给后取**:在这些地方**先提供具体价值**(认真回答问题、做免费拆解),建立「这个人有料」的印象,而不是上来发链接。
3. **一对一转化**:把对你内容感兴趣的人,**手动**引导到你的主阵地(私信、评论区置顶)。前 100 个可以是你亲手聊来的。
4. **挖反馈**:对前 100 个读者主动问「你为什么关注/取关?哪条最有用?」——这个阶段反馈比涨粉重要。
5. **找可重复动作**:观察哪个「鱼塘 + 给价值」的组合带人最稳,把它变成可重复的日常动作,而不是等下一个爆款。

## 输出格式

```
【目标读者聚集的具体鱼塘】（具体到群/话题/小组，至少 3 个）
  - ……
【在每个鱼塘先给的价值】（不是发链接，是给什么）
  - ……
【手动转化动作】把人带回主阵地的具体做法：……
【前 100 个读者的反馈问题】……
【已验证的可重复动作】哪个组合最稳 → 变成日常
```

## 示例

Input:「我想做 AI 工具测评号,但现在 0 粉丝,发了几条没人看,不知道怎么开始。」
Output:
- 鱼塘:即刻「AI 探索」圈子、V2EX 分享节点、几个 AI 工具讨论的微信群、Reddit r/artificial。
- 先给价值:在这些地方认真回答「X 工具好不好用」的提问,附自己的实测截图,不发号。
- 手动转化:回答末尾自然带一句「我把更多实测整理在了 __」,感兴趣的人自己来。前 100 个这样聊来。
- 反馈:私信问前 50 个关注者「你最想看哪类工具测评」。
- 可重复动作:发现「即刻回答提问 + 附实测」最稳,定为每日动作。不再等爆款,而是每天挣 5-10 个真实读者。
