# 简历改写:从「我会什么」到「我能帮你完成什么」

## 目标

给用户一套可操作的方法,把简历从**自我视角的经历罗列**,改成**雇主视角的价值陈述**——每一条都回答「这对要招人的人意味着什么」。

> 配合 `jtbd`:雇主「雇用」一个岗位是为了完成某个任务。简历就是论证「我能完成那个任务」。

## 立场 (Stance)

绝大多数没回音的简历,病根是**写给自己看,不是写给雇主看**。

- **自我视角(无效)**:「负责运营公众号」「熟练使用 Python」「参与了某项目」。这些只说了你**做过/会**,没说**带来了什么结果、能为雇主解决什么**。
- **雇主视角(有效)**:HR 只关心一件事——「招了你,我的什么问题被解决?」每一条经历都要翻译成「我做了 X,带来了可量化的 Y」。
- **可量化是信任的来源**:「提升了运营效果」是空话;「3 个月把公众号阅读量从 500 做到 1 万」是证据。数字让承诺可信。
- **边界**:这个 skill 改的是**表达**,不是帮你编造经历。没有的成果不能造——夸大会在面试被戳穿,代价是信任崩塌。

## 使用流程

1. **先定目标岗位**:不同岗位要完成的任务不同,简历要针对性重构。泛简历等于没简历。
2. **逐条体检**:把现有每条经历拿出来,问「这条说清了『带来什么结果』吗?还是只说了『做过什么』?」
3. **套用 STAR/成果公式**:把每条改成「做了什么(动作)+ 怎么做的(方法)+ 带来什么可量化结果(数字)」。
4. **量化**:逼出数字——百分比、绝对值、时间、规模。真的没数字,用「相对变化」或「具体规模」替代(「从 0 搭建」「覆盖 X 人」)。
5. **匹配岗位关键词**:对照目标岗位的任务,确保你的经历论证了「我能完成它」。删掉和目标无关的经历。
6. **删空话**:删掉「认真负责」「学习能力强」这类无法验证的形容词——它们占位置且零信息。

## 输出格式

```
【目标岗位 & 它要完成的核心任务】……
【逐条改写】
  原文：……（自我视角）
  改写：……（雇主视角 + 可量化结果）
【删除建议】无法验证的空话 / 与目标无关的经历：……
【还缺的论证】要完成目标岗位的任务，你的简历还没证明的点：……
```

## 示例

Input:「我简历上写『负责学生会公众号运营,工作认真负责』,投运营岗没回音。」
Output:
- 目标岗位的核心任务:运营岗要完成的是「让内容触达更多人、带来增长」。
- 逐条改写:
  - 原文:「负责学生会公众号运营,工作认真负责」(自我视角 + 空话)
  - 改写:「独立运营学生会公众号,通过选题改版 + 固定栏目,半年内将单篇阅读从 200 提升到 1500(7.5 倍)」
- 删除建议:「工作认真负责」——无法验证,删。
- 还缺的论证:运营岗常看「涨粉/转化」,如果你有粉丝增长数据,补上;没有就突出阅读量增长这个可量化结果。
