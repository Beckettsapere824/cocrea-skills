# 差异化定位:一句话说清「凭什么是你」

## 目标

帮用户提炼一句**差异化定位**:在一堆竞争者里,说清「我能为谁解决什么独特问题、凭什么是我」,让人记住并选择你。

## 立场 (Stance)

「我什么都能做、我很全能」是**最弱的定位**,等于没有定位。

- **全能 = 没有记忆点**:当你说「我营销、运营、设计、写作都会」,对方记不住你,也不信你哪个都强。在选择里,**清晰的窄定位**比模糊的广定位更容易被选中。
- **定位是减法,不是加法**:好定位敢于舍弃——明确「我不做什么」,才能让「我做什么」变得锐利。
- **差异化来自交叉**:你未必在单一维度最强,但「A 能力 × B 背景 × C 视角」的交叉点上,你可能是稀缺的。定位就是找到这个交叉点。
- **边界**:定位是「聚焦你已有的真实优势」,不是编造人设。立不住的定位面试/合作一聊就穿。

## 使用流程

1. **列原料**:让用户列出自己的能力、经历、背景、独特视角(不评判,先铺开)。
2. **找交叉点**:从原料里找「组合起来稀缺」的交叉(如「懂技术 + 会表达」「学医 + 做自媒体」),而不是单一最强项。
3. **锁定对象**:定位必须有「为谁」——你要解决谁的问题?越具体越有力。
4. **填定位句**:套用句式「我帮 <谁> 解决 <什么问题>,因为我 <独特交叉点>」。
5. **做减法**:逼用户砍掉为了「显得全能」而堆的标签,只留最锐利的那条。
6. **验证记忆点**:问「听完这句,对方能用一句话向别人转述你吗?」不能 → 还不够清晰。

## 输出格式

```
【你的原料】能力/经历/背景/视角……
【稀缺的交叉点】（组合起来才稀缺的）……
【服务对象】我要解决谁的问题：……
【定位句】我帮 <谁> 解决 <什么>,因为我 <交叉点>。
【砍掉的标签】为显全能而堆的、稀释定位的：……
【记忆点验证】对方能转述吗？✓/✗
```

## 示例

Input:「面试自我介绍我总说『我学习能力强、适应快、什么都愿意学』,感觉很普通。」
Output:
- 原料:学的是会计、自己运营了一个记账方法的小红书、喜欢把复杂的东西讲简单。
- 稀缺交叉点:「财会专业知识 × 内容表达能力」——既懂专业又能讲清楚,这个组合稀缺。
- 服务对象:需要「把专业内容做成大众听得懂的传播」的财经/教育类岗位。
- 定位句:「我能把枯燥的财会知识讲成普通人听得懂的内容——我有会计专业底子,也用小红书验证过自己的科普表达能力。」
- 砍掉:「学习能力强、适应快、什么都愿意学」——人人都这么说,零差异,删。
- 记忆点验证:✓,面试官能转述「那个会计专业、会做科普的女生」。
