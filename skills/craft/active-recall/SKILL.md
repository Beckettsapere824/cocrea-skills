# 主动回忆:合上书,才是真复习

## 目标

给用户一套可操作的方法,用**主动回忆**(合上材料、凭记忆把内容生成出来,再对照检查)替代**被动重读**,大幅提升记忆效率——这是认知科学里证据最强的学习方法之一(testing effect)。

## 立场 (Stance)

最普遍、也最低效的复习方式是**反复重读和划线**。它感觉很舒服、很有进度("我又看了一遍"),但记忆留存率很低。

- **为什么重读没用**:重读时,材料就在眼前,大脑产生「我认识它」的**熟悉感**,误以为「记住了」。但考试时材料不在眼前,你要的是**从空白里调出来**的能力——这正是重读从不训练的。
- **为什么主动回忆有效**:合上书、强迫自己回忆,是在直接练习「提取」这个动作。每次成功提取都强化记忆通路;卡住的地方精准暴露你的薄弱点。提取的「费力感」正是它有效的原因——**舒服的学习通常是无效的**。
- **判断尺**:如果你的复习全程材料都开着、眼睛在扫,你在做被动输入,不是在记忆。真正的复习一定包含「合上,自己说一遍」。
- **边界**:主动回忆是高效记忆手段;但要先**理解**了才值得记(配合 feynman-technique)。对没理解的东西硬背,效率仍低。

## 使用流程

1. **诊断现状**:用户的复习是不是以重读/划线/抄笔记为主?如果是,指出这是被动输入。
2. **先输入一遍**:正常读/学一遍材料(这步是必要的,但只是开始,不是全部)。
3. **合上,提取**:盖住材料,凭记忆把核心内容写出来或讲出来——这是核心动作。
4. **对照,标漏**:打开材料对照,标出没回忆出来的、记错的部分。
5. **只攻薄弱点**:针对标出的漏洞重新学,然后再次合上提取,而不是从头重读。
6. **用问题驱动**:把材料转成「问题」形式(给自己出题),靠回答问题来复习,比顺着读高效得多。

## 输出格式

```
【你现在的复习方式】被动（重读/划线）/ 主动（自测/复述）
【第一遍输入】（正常学一遍）
【合上后的提取】凭记忆生成的内容：……
【对照标出的漏洞】没回忆出/记错的：……
【自测题】把材料转成的问题：……
```

## 示例

Input:「下周考试,我打算把课本和笔记从头到尾再读三遍,但以前这么做考完就忘。」
Output:
- 现状:从头读三遍 = 被动输入,这就是「考完就忘」的原因——你在训练「熟悉感」,不是「提取能力」。
- 第一遍输入:正常读一遍课本/笔记,把框架过一遍。
- 合上提取:盖住书,拿张白纸,凭记忆默写出这一章的核心概念和它们的关系。
- 对照标漏:打开书对照,红笔标出没写出来的、写错的——这些就是你真正没掌握的(往往只占全章 20%)。
- 只攻薄弱点:别再读三遍全书。只回去搞这 20%,然后再合上默写一遍。
- 自测题:把每个知识点改成问题(「机会成本为什么不是所有放弃项之和?」),靠答题复习,效率远高于顺读三遍。
