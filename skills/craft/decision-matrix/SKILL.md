# 决策矩阵:把纠结拆成可比较的结构

## 目标

给用户一个可操作的工具,把「在几个选项间反复横跳」的模糊纠结,拆成「选项 × 加权标准」的表格——逼出你真正在乎什么、每个选项在这些维度上表现如何,让隐性权衡显性化。

## 立场 (Stance)

纠结的本质,往往是**多个标准在脑子里打架,且你没意识到自己给它们的权重**。决策矩阵的价值不是「算出一个标准答案」,而是**逼你把藏在直觉里的权衡摊到桌面上**。

- **它真正的作用**:不是替你决定,而是让你看清「我原来这么在乎稳定性」或「我嘴上说看重 A,但打分时给 B 的权重更高」。很多时候填完矩阵,你对自己的真实偏好就清楚了。
- **garbage in, garbage out**:矩阵的质量取决于你选的标准和权重。如果标准选错、权重不诚实,算出来的也是错的。它放大你的思考,不替代你的思考。
- **它不是裁判,是镜子**:如果算出来的最高分让你心里「咯噔一下、不太情愿」,这个不情愿本身是极宝贵的信息——说明有个你没列进去的重要标准。别盲从分数,要读这个信号。
- **边界**:对高度不确定的赌注(结果取决于未知)或纯情感/价值的选择,矩阵只是辅助,配合 bayesian-thinking 和你自己的价值判断用。

## 使用流程

1. **列全选项**:把所有可行选项列出来(含容易被忽略的「都不选」「再等等」)。
2. **挖标准**:问「你做这个决定,真正在乎的是哪几件事?」(如收入、成长、稳定、兴趣、地点、风险)——逼出 4-6 个,别漏掉那些「不好意思说但其实很在乎」的。
3. **定权重**:给每个标准分配权重(如 1-5 分或百分比)。**这一步最关键**——权重暴露你的真实偏好。
4. **逐格打分**:每个选项在每个标准上打分(如 1-10)。
5. **加权求和**:权重 × 得分,算出每个选项的总分。
6. **读"咯噔"信号**(关键):看最高分选项,问用户「这个结果你服气吗?如果心里抗拒,是哪个没被列进去的标准在作祟?」——把它补进矩阵重算。

## 输出格式

```
【选项】（含"不选/再等"）……
【真正在乎的标准 & 权重】
  - 标准A（权重 __）
  - 标准B（权重 __）
【打分矩阵】
            标准A  标准B  ...  加权总分
  选项1      _      _          __
  选项2      _      _          __
【最高分】……
【"咯噔"检查】这个结果你服气吗？抗拒说明漏了什么标准：……
```

## 示例

Input:「我手上两个 offer,一个大厂钱多但加班狠,一个小公司钱少但能学很多还离家近,纠结死了。」
Output:
- 选项:大厂 / 小公司 /(补充:有没有"再谈一轮薪资/再等其他 offer")。
- 标准 & 权重:逼你定——收入(权重?)、成长(?)、工作强度/健康(?)、通勤/生活(?)。你给"成长"和"离家近"的权重,会暴露你嘴上说看钱但其实更在乎什么。
- 打分:大厂在收入上 9、强度上 3;小公司收入 5、成长 8、通勤 9……
- 加权总分:算出来假设小公司略高。
- 咯噔检查:如果算完是小公司高,但你心里失落 → 说明"收入/面子"的真实权重比你填的高,或你漏了"长期平台背书"这个标准。把它补进去重算,直到结果和你的内心对上。矩阵帮你发现了你真正在乎的。
