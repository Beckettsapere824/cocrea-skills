# 求职定位包

## 这个包帮你做什么

把一个「投了很多没回音 / 不知道自己适合什么 / 靠考证缓解焦虑」的求职者,拉回到对的路径:
**先看清你真正在选什么、雇主要的是什么,拦住海投和考证焦虑两个陷阱,再动手做出清晰定位和有说服力的简历。**

最终把「我很努力但找不到工作」的迷茫,变成「我清楚自己适合什么、凭什么被选中、该针对性投给谁」。

## 整体立场

我们相信求职者最大的两个杀手不是「能力不够」,而是:
**① 用「努力的姿态」(海投、考证)逃避「定位不清」的真问题;② 把简历写给自己看,而不是写给雇主看。**

这个包的默认倾向,是逼你**面对方向问题、聚焦差异化**,而不是教你怎么投更多、考更多。我们和「广撒网 + 多考证总没错」的内卷逻辑刚好相反——那套逻辑放大的是失败和焦虑,不是机会。

## 包含的 Skills 与推荐顺序（自然语言工作流）

> 这套顺序由**你的 AI 读懂下面这段话后自己串起来执行**,不需要任何引擎。
> 加载本包后,对你的 agent 说「帮我看看我的求职/定位问题」,它会按此顺序走:

1. **opportunity-cost**（方法/lens）— 先看清你在选什么:考研/某 offer/继续准备的真代价,是你放弃的最优选项,不是显性花费。
2. **jtbd**（方法/lens，跨包复用）— 看清雇主「雇用」这个岗位是为了完成什么任务——你的简历就是论证「我能完成它」。
3. **anti-mass-application**（护栏/guardrail）— 拦住海投冲动,别用投递数量逃避定位不清。
4. **anti-credential-anxiety**（护栏/guardrail）— 拦住考证焦虑,别用「我在提升」逃避「我没方向」。
5. **positioning-statement**（工具/craft）— 动手提炼一句话差异化定位:凭什么是你。
6. **resume-rewrite**（工具/craft）— 把简历从「我会什么」改写成「我能为你解决什么、带来什么可量化结果」。

**为什么是这个顺序**:先校准「选择的真代价 + 雇主视角」(1-2 方法层),再「拦住两个用努力逃避方向的陷阱」(3-4 护栏层),最后「落到能交付的定位和简历」(5-6 工具层)。看 → 拦 → 做。

## 适用 / 不适用

- **适用**:应届求职、转行、对方向迷茫、投递没回音、靠海投/考证缓解焦虑的人。
- **不适用**:已有清晰方向和成熟履历、要解决的是高阶谈薪/职业跃迁——那时你需要进阶的职业策略工具,不是定位包。
