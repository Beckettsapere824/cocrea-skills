# 人生决策包

## 这个包帮你做什么

把一个面临重大选择(考研还是工作、留下还是离开、A offer 还是 B、要不要止损)的人,从"反复横跳、被情绪和过去绑架"拉回到清醒判断:
**先用概率和机会成本看清这个决定,拦住沉没成本和决策瘫痪两个陷阱,再用决策矩阵把纠结拆成可比较的结构。**

最终把"我不知道怎么选、想了好久还是定不下来"的内耗,变成"我清楚这个决定该慎重还是该快试、我真正在乎什么、什么在绑架我"。

## 整体立场

我们相信人在重大决策上最大的两个杀手,不是"不够聪明",而是:
**① 被沉没成本绑架(用过去的投入逼自己继续错下去);② 在可逆的小事上过度分析、在不可逆的大事上又草率。**

这个包的默认倾向,是帮你**把决策依据放在"从现在往前"的未来、并分清哪些决定值得慎重、哪些该快速试错**,而不是给你一个"标准答案"。我们不替你做决定——决策矩阵是镜子不是裁判,最终选择和价值判断永远是你自己的。

## 包含的 Skills 与推荐顺序（自然语言工作流）

> 这套顺序由**你的 AI 读懂下面这段话后自己串起来执行**,不需要任何引擎。
> 加载本包后,对你的 agent 说「帮我看看我这个纠结的决定」,它会按此顺序走:

1. **bayesian-thinking**（方法/lens）— 先把"非黑即白的认定"改成"随证据更新的概率",看清这件事的真实把握有多大、还缺什么关键信息。
2. **opportunity-cost**（方法/lens，跨包复用）— 看清每个选项的真代价是你放弃的最优选项,而不是显性花费。
3. **anti-sunk-cost**（护栏/guardrail）— 拦住"已经投入太多放弃可惜"的绑架,只看未来不看过去。
4. **anti-analysis-paralysis**（护栏/guardrail）— 拦住过度分析:先判断这决定可逆吗?可逆的别再想了,去试。
5. **decision-matrix**（工具/craft）— 对值得慎重的(不可逆)决策,把纠结拆成"选项 × 加权标准",逼出你真正在乎什么。

**为什么是这个顺序**:先校准"判断的尺子"(1-2 方法层:概率 + 真代价),再"拦住两个最毁决策的陷阱"(3-4 护栏层:沉没成本 + 瘫痪),最后"对真正该慎重的决策落到可比较的结构"(5 工具层)。看 → 拦 → 做。

> 注意第 4 步(反决策瘫痪)是这个包的关键分流器:它先判断"可逆还是不可逆"。可逆 → 别用矩阵,直接去试;不可逆 → 才进第 5 步用矩阵慎重分析。这避免了"杀鸡用牛刀"地把小决定也搞成大工程。

## 适用 / 不适用

- **适用**:面临具体重大选择且陷入纠结/内耗的人——升学就业、去留、止损、重大投入。
- **不适用**:纯价值观/情感的选择(我想成为什么样的人、爱不爱一个人)——这些工具能辅助厘清,但答案只能你自己给,不要指望框架替你回答。
