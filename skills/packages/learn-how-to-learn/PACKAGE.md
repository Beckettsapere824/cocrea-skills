# 学会学习包

## 这个包帮你做什么

把一个「很努力但学不好 / 收藏一堆从不消化 / 读很多遍还是记不住」的学习者,拉回到对的方法:
**先看清学习是复利的(短期没效果是正常的),拦住囤积资料和低效勤奋两个幻觉,再用费曼和主动回忆这两个被验证的方法真正学会。**

最终把「我这么努力为什么没用」的挫败,变成「我知道哪些努力是假的、哪些方法是真有效的」。

## 整体立场

我们相信学习者最大的敌人不是「不够努力」,而是:
**① 用「形式上的勤奋」(囤资料、抄笔记、熬时长)冒充「真实的学习」;② 用「短期没效果」误判一件本质上靠长期复利的事。**

这个包的默认倾向,是帮你**把努力放在费脑的地方、用产出而非投入衡量学习**,而不是教你更多「看起来很努力」的技巧。我们和「3 小时速成 X」「100 个必收藏干货」的套路刚好相反——那些放大的是你的焦虑和囤积,不是你的能力。

## 包含的 Skills 与推荐顺序（自然语言工作流）

> 这套顺序由**你的 AI 读懂下面这段话后自己串起来执行**,不需要任何引擎。
> 加载本包后,对你的 agent 说「帮我看看我的学习方法问题」,它会按此顺序走:

1. **compounding**（方法/lens）— 先看清学习是复利的:前期看不到效果是正常的,中断才是真正的敌人。用短期收益判断学习,本身就是错的尺子。
2. **anti-collection-hoarding**（护栏/guardrail）— 拦住囤积冲动:收藏 ≠ 学会,保存资料的动作不产生任何学习。
3. **anti-fake-diligence**（护栏/guardrail）— 拦住低效勤奋:抄笔记/熬时长是用辛苦冒充学到,把努力放回费脑的地方。
4. **feynman-technique**（工具/craft）— 用「讲给外行听」检验理解:讲不清的地方就是没真懂的地方。
5. **active-recall**（工具/craft）— 用「合上书自测」代替被动重读:训练提取能力,而不是熟悉感。

**为什么是这个顺序**:先校准「学习的时间观」(1 方法层),再「拦住两个最常见的假学习」(2-3 护栏层),最后「落到两个被验证的有效方法」(4-5 工具层)。看 → 拦 → 做。

> 本包护栏占两席(囤积 + 低效勤奋),因为学习领域的核心问题恰恰是「用假努力逃避真学习」——这正是 CoCrea 护栏层结构性的价值所在。

## 适用 / 不适用

- **适用**:学生备考、自学转行、知识工作者——尤其是「很努力但效果差 / 资料囤一堆 / 学完就忘」的人。
- **不适用**:已有高效学习系统、要解决的是特定领域的深度钻研方法——那时你需要该领域的专门方法,不是通用学习包。
