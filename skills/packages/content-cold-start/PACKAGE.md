# 内容创作冷启动包

## 这个包帮你做什么

把一个「想做内容但没人看 / 刚起步没粉丝」的创作者,从对的地方开始:
**先看清你在和什么抢注意力、你在为谁创作,再拦住追热点和数据焦虑两个陷阱,最后动手设计钩子、挣到前 1000 个真实读者。**

最终把「我内容很好为什么没人看」的困惑,变成「一套不靠运气、可重复的冷启动动作」。

## 整体立场

我们相信内容创作者的两个最大杀手不是「不会做内容」,而是:
**① 把希望寄托在爆款和热点上(用运气代替策略);② 被虚荣指标绑架(优化错了目标)。**

这个包的默认倾向,是帮你**建立能复利的内容资产 + 盯对的指标**,而不是教你怎么更快地蹭一波流量。我们和「教你 7 天涨粉 10 万」的套路刚好相反——那种涨法涨来的,往往是离你真实目标更远的虚荣数字。

## 包含的 Skills 与推荐顺序（自然语言工作流）

> 这套顺序由**你的 AI 读懂下面这段话后自己串起来执行**,不需要任何引擎。
> 加载本包后,对你的 agent 说「帮我看看我的内容/账号怎么冷启动」,它会按此顺序走:

1. **attention-economy**（方法/lens）— 先看清:你不是在和同行抢,是在和「一切」抢读者有限的注意力。
2. **jtbd**（方法/lens，跨包复用）— 看清你的读者在什么处境下、要「雇用」你的内容完成什么任务,戳破「我想表达什么」式的自嗨。
3. **anti-trend-chasing**（护栏/guardrail）— 拦住「追热点」冲动,区分搭热点(可以)和搬运(陷阱)。
4. **anti-vanity-metrics**（护栏/guardrail）— 拦住数据焦虑,别被点赞/粉丝数绑架,盯对的行动指标。
5. **hook-design**（工具/craft）— 动手设计钩子,3 秒内让人停下,且不透支信任。
6. **cold-start-first-1000**（工具/craft）— 用「做不规模化的事」挣到前 1000 个真实读者。

**为什么是这个顺序**:先校准「战场认知 + 受众」(1-2 方法层),再「拦住两个最致命的陷阱」(3-4 护栏层),最后「落到能动手的钩子和冷启动动作」(5-6 工具层)。看 → 拦 → 做。

## 适用 / 不适用

- **适用**:想做或刚起步做内容(自媒体/公众号/视频号/独立博客),没什么粉丝,困惑于「好东西没人看 / 怎么开始」。
- **不适用**:已有稳定受众、要解决的是规模化增长或商业化深水区——那时你需要增长/商业化的进阶工具,不是冷启动包。
