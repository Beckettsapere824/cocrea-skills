# 内倾思维(Ti)镜头:逼问逻辑到底站不站得住

## 目标

用 Ti 这把镜头,把一个听起来顺、其实含糊的想法,拆到定义清晰、前提自洽、没有偷换概念为止。

## 立场 (Stance)

Ti 极擅长戳破「听起来对、其实空」的话,但它的失效模式很危险:
- 它会陷入**象牙塔式正确**——把一个内部自洽的模型打磨到完美,却从不接触现实、不管有没有人需要(这正是 anti-over-engineering 的认知根源)。
- 它会在**不需要精确的地方要求精确**,导致迟迟不动手(决策瘫痪)。

**不该单用 Ti 的场景**:信息不全但必须快速行动时;选错代价很小、试一下比想清楚更快时。

> **关键:这是镜头,不是身份判决。** 哪怕你不是「逻辑型」,也能用它检查自己的想法;哪怕你 Ti 很强,也要警惕它让你困在「想清楚」里不肯下场。

### 可迁移到哪（lens 层核心）

「逼问逻辑自洽」可搬到:概念澄清(剥掉大词看本质)、写作论证(找出论证漏洞)、产品定义(到底解决谁的什么)、学习理解(真懂还是背了术语)。

## 使用流程

1. **抓出关键词**——把那些模糊大词(赋能/生态/帮助/优化)挑出来。
2. **逐个下定义**——逼问「这个词在这里到底指什么」,不许用另一个大词解释大词。
3. **检查前提**——这个想法成立,默认了哪些没说出口的假设?它们真的成立吗?
4. **找内部矛盾**——前后两句话是否打架?有没有偷换概念?
5. **判断够不够**——逻辑通了之后,问一句「这件事需要我想到这么清楚才能动手吗,还是已经够了」。

## 输出格式

> （模仿 Ti 的认知风格：精确、拆解、找矛盾）

```
【模糊关键词】……
【逐个下定义】X = ……（不许用大词解释大词）
【隐藏前提】这个想法默认了：……（成立吗？）
【内部矛盾/偷换概念】……
【够了吗】逻辑已通；这件事是否需要想到这么清才动手：……
```

## 示例

Input:「我想做一个赋能大学生成长的平台。」
Output:抓出「赋能」「成长」「平台」三个大词 → 逼问:赋能=具体给他什么?成长=哪方面、怎么衡量?平台=和一个微信群有何本质不同? → 暴露隐藏前提「大学生需要一个平台来成长」(真的吗?) → 结论:在这些词被定义成具体动作之前,这还不是一个想法,是一句口号。
