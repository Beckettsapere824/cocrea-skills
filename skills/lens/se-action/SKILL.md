# 外倾感觉(Se)镜头:拉回当下,马上动手

## 目标

用 Se 这把镜头,把一个困在「想、计划、纠结」里的人,拉回到眼前的真实现实:此刻确凿存在的是什么、现在立刻能做的一步是什么。

## 立场 (Stance)

Se 是行动力和临场感的来源——它让你抓住眼前的机会、在真实世界里直接试,而不是在脑中空转(这是 anti-analysis-paralysis 的认知解药)。但它的失效模式也很明显:
- 它会让你**只顾眼前、不想后果**,冲动行事、追求即时刺激。
- 它会**忽略长期主线**(那是 Ni 的领地),为了「现在爽/现在动」而偏离方向。

**不该单用 Se 的场景**:决定不可逆、代价巨大、需要深思时;长期布局比眼前一步更重要时。

> **关键:这是镜头,不是身份。** 你不需要「是个行动派」才能用它。对一个习惯了想清楚再动、结果永远在想的人,刻意拿起这把镜头问一句「现在这一秒我能做的最小一步是什么」,就是破局。

### 可迁移到哪（lens 层核心）

「拉回当下、马上动手」可搬到:快速执行(可逆的事先做再说)、临场应变、克服拖延、抓住转瞬即逝的机会。

## 使用流程

1. **打断脑内循环**——先承认:你已经想得够多了,缺的不是想,是动。
2. **看眼前的真实现实**——抛开假设和担忧,此刻确凿存在的事实是什么、你手上真实有的资源是什么。
3. **找「现在这一秒就能做」的最小一步**——小到不可能失败、不需要任何准备就能开始的那一步。
4. **立刻做掉它**——不是今天、不是等会儿,是现在。
5. **做完再调**——行动会产生新信息,拿新信息再决定下一步,而不是在行动前想穷所有情况。

## 输出格式

> （模仿 Se 的认知风格：当下、具体、立刻、不啰嗦）

```
【你已经想够了】停。缺的不是想，是动。
【眼前的真实】此刻确凿存在的：…… / 手上真有的资源：……
⚡【现在这一秒能做的最小一步】……（小到不可能失败）
【立刻做】不是等会儿，是现在。
【做完再说】行动产生的新信息：……→ 据此定下一步
```

## 示例

Input:「我计划做个播客好几个月了,设备、选题、片头音乐都研究了,但一期都没录。」
Output:停——你研究了几个月,缺的不是研究是开录 → 眼前真实:你有手机(能录音)、有想说的话题、有这一刻的时间 → ⚡最小一步:现在用手机录音 App,就你最想聊的那个话题,录 5 分钟,不要剪辑不要片头 → 立刻做,现在,不是等设备到齐 → 做完你会立刻知道:你到底喜不喜欢对着麦说话、哪里卡壳——这些是几个月的计划给不了你的。完美设备永远在路上,第一期只能靠现在按下录音键。
