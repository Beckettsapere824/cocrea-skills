# 注意力经济：你在和「一切」抢注意力

## 目标

让用户从「我的内容好不好」转向「在读者有限的注意力里，我凭什么被选中」——理解注意力是**总量恒定、零和争夺**的稀缺资源。

## 立场 (Stance)

「我内容质量很高但没人看」这句抱怨里藏着一个错误假设：**质量高就该被看到**。

真相是:读者的注意力总量是恒定的(一天就那么多),你不是在和同领域创作者竞争,你是在和**睡觉、游戏、短视频、朋友的消息**一起争夺同一份注意力。质量是入场券,不是胜负手。

- **这个 lens 让你看清战场**:被选中靠的是「相关性 × 即时价值 × 低认知成本」,不是绝对质量。
- **但它不是标题党的许可证**:理解注意力争夺 ≠ 用欺骗换点击。骗来的注意力会用信任偿还。lens 解释战场，不发放降低底线的牌照。
- **边界**:它解释「为什么没被看到」,不替你判断「这个内容值不值得做」——那是 jtbd 和你自己的事。

### 可迁移到哪（lens 层核心）

「在有限注意力里争夺被选中」可搬到:
- **演讲/汇报**:听众的注意力前 30 秒就流失,开头凭什么留住人?
- **产品设计**:用户打开 app 的前 3 秒,凭什么不划走?
- **求职**:HR 看一份简历 7 秒,你凭什么被多看一眼?

## 使用流程

1. **打破「质量自证」**:先让用户承认,好东西不会自动被看到——注意力要主动争取。
2. **列竞争对象**:不是同行,是读者刷到你之前/之后那一条。问「他为什么停在你这,而不是划走?」
3. **算认知成本**:你的内容让读者「搞懂它值不值得看」要花几秒?成本越高越被划走。
4. **找即时相关性**:读者凭什么觉得「这和我有关、现在有用」?没有相关性,质量再高也被跳过。
5. **给停留理由**:产出一个「前 3 秒就成立」的被选中理由(配合 hook-design 落地)。

## 输出格式

```
【你以为的竞争对手】同领域创作者
【真正的竞争对手】读者刷到你前后的那一切（含睡觉/游戏）
【你的认知成本】读者判断「值不值得看」要花 __ 秒 → 偏高/可接受
【即时相关性】读者凭什么觉得「和我有关、现在有用」：……
【被选中的理由（前3秒成立）】……
```

## 示例

Input:「我写了一篇 5000 字深度行业分析,数据很扎实,但只有几十个阅读。」
Output:
- 你以为的对手:其他行业分析号。真正的对手:读者那一刻刷到的搞笑视频、朋友消息。
- 认知成本:5000 字 + 「深度行业分析」标题 = 读者要花很多秒判断值不值得读 → 太高,直接划走。
- 即时相关性:标题没告诉读者「这对我现在有什么用」。
- 被选中理由:把结论前置——「这个行业明年要洗牌,3 个信号现在就能看到」,让读者 3 秒内知道读它的回报。质量没问题,是入口的注意力设计缺失。
