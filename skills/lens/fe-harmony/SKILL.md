# 外倾情感(Fe)镜头:看清这件事对人意味着什么

## 目标

用 Fe 这把镜头,把一个只算了「事」和「利弊」的决定,放回到「人」的语境里:它会怎样影响身边人的感受、关系和整体氛围。

## 立场 (Stance)

Fe 擅长读懂群体情绪、维护关系、让人愿意一起做事——这是纯逻辑(Te/Ti)的盲区。但它的失效模式也明确:
- 它会**为了维持表面和谐而回避必须说的真话**,牺牲长期利益换短期不尴尬。
- 它会**过度在意别人怎么想**,以至于丢掉自己的立场(那是 Fi 的领地,两者要平衡)。

**不该单用 Fe 的场景**:需要做不受欢迎但正确的决定时;对方的情绪其实是操纵手段时。

> **关键:这是镜头,不是身份。** 这把镜头对效率驱动、习惯只看事不看人的人(典型的 Te 型创始人)尤其重要——不是因为你「该变成感性的人」,而是因为忽略人的感受会让正确的决定也执行不下去。哪怕你天性不擅长,也能刻意拿起它。

### 可迁移到哪（lens 层核心）

「看见决定对人的影响」可搬到:团队协作(变动前先想成员感受)、用户共情(产品决策背后真实的人)、谈判沟通(对方要的不只是条件,还有被尊重)、关系维护。

## 使用流程

1. **列出这个决定牵动到的人**——谁会因此受影响,哪怕是间接的。
2. **站到每个人的位置上**——对他来说,这件事意味着什么?他会有什么感受?
3. **找被纯利弊账忽略的代价**——有没有「账面划算但伤了关系/士气」的隐性成本?
4. **想怎么沟通**——同样的决定,怎么说、何时说,能让人愿意接受而不是被冒犯。
5. **回到平衡**——用 Fi 检查:为了照顾别人,我是不是丢了自己该守的立场?

## 输出格式

> （模仿 Fe 的认知风格：以人为单位、关注感受与关系）

```
【牵动到的人】……
【各自的处境与感受】对 A 来说…… / 对 B 来说……
【被利弊账忽略的关系成本】……
【怎么沟通才不伤人】说什么 / 何时说 / 怎么说
【平衡检查】为照顾别人，我有没有丢掉自己的立场（Fi）：……
```

## 示例

Input:「我决定砍掉合伙人负责的那个方向,纯粹从数据看它不值得做。」
Output:牵动到的人=合伙人、跟着做这块的成员 → 对合伙人:这是他投入心血的方向,被砍等于否定他的判断,会感到挫败甚至不被信任 → 被忽略的成本:数据上省了,但可能伤了合伙人的投入感和团队信任,这比那个方向的损失更贵 → 沟通:别用「数据说不行」一句带过,先承认他的投入、一起看数据、让他参与决定怎么收尾 → 平衡:照顾感受不等于不砍,该砍还砍,但怎么砍决定了关系的存续。
