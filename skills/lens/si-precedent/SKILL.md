# 内倾感觉(Si)镜头:翻出过去的经验作参照

## 目标

用 Si 这把镜头,把一个「凭感觉重新开始」的决定,放到你过去的真实经验旁边对照:类似的事发生过吗、那次的细节和教训是什么、这次是不是在重蹈覆辙。

## 立场 (Stance)

Si 是经验沉淀和稳定性的来源——它让你不必每次都从零踩坑,把过去的教训变成这次的护栏。但它的失效模式同样致命:
- 它会让你**因为「以前没这么干过」而拒绝新东西**,把过去当成不可逾越的标尺(这是 Ne 的反面)。
- 它会**过度纠结细节和旧规矩**,在不该保守的时候保守。

**不该单用 Si 的场景**:面对全新的、过去没有参照的局面时;环境已经变了、旧经验反而误导时(刻舟求剑)。

> **关键:这是镜头,不是身份。** 你不需要「是个念旧的人」才能用它。对一个总是兴冲冲重启、却忘了上次怎么失败的人(典型的 Ne/Se 驱动者),刻意拿起这把镜头问一句「这事我以前栽过吗」,能省下重复的代价。

### 可迁移到哪（lens 层核心）

「调出经验作参照」可搬到:复盘总结、风险预判(这类事过去怎么出错的)、习惯养成(哪些做法被验证有效)、经验复用(别重造已有的轮子)。

## 使用流程

1. **找到类比的过去经验**——这件事让你想起以前的什么?自己的或见过别人的。
2. **还原那次的细节**——具体发生了什么、关键节点是什么、结果如何(别只记一个模糊印象)。
3. **提取教训**——那次成功/失败的真正原因是什么?哪个细节是关键?
4. **对照这次**——这次和那次,哪里一样(教训适用)、哪里不一样(环境变了,旧经验可能误导)。
5. **判断借鉴还是放下**——确认旧经验在这次是护栏还是枷锁,别刻舟求剑。

## 输出格式

> （模仿 Si 的认知风格：回溯、细节、对照过去）

```
【这次的事】……
【它让我想起的过去经验】……（自己的/别人的）
【那次的细节与结果】具体发生了……→ 结果……
【提取的教训】真正的关键是……
【这次 vs 那次】一样的地方（教训适用）：…… / 不一样（环境变了，慎用）：……
【借鉴还是放下】……（别刻舟求剑）
```

## 示例

Input:「我又想拉几个朋友一起搞个项目,这次做电商,大家都很有热情。」
Output:这次=拉朋友合伙做项目 → 想起的经验:上次也是一群朋友热情满满搞社团/项目 → 那次细节:开头热火朝天,但没分清谁负责什么、没说好利益怎么分,三个月后热情退了、活儿全压你一个人、最后不欢而散 → 教训:朋友合伙的杀手不是能力,是「角色和利益没在热情期说清楚」 → 这次 vs 那次:一样的是「靠热情起步、关系亲密不好意思谈钱」——教训完全适用;不一样的是这次做电商有真实现金流,可以用分账机制化解 → 借鉴:这次开头就把「谁负责什么、钱怎么分、做不下去怎么退出」白纸黑字写清楚,别再用第二次不欢而散验证同一个教训。
