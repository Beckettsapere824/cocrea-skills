# 内倾直觉(Ni)镜头:剥掉噪音,看出那根主线

## 目标

用 Ni 这把镜头,把一堆看似无关的事、太多的选项,收敛成「它们其实都指向的那一个方向」,看清长期的走向。

## 立场 (Stance)

Ni 是战略和洞察的来源,但它的失效模式最隐蔽也最危险:
- 它会让你**对一个其实只是猜测的『愿景』过度确信**,然后无视所有和它矛盾的数据(确认偏误的高级版,见 bayesian-thinking)。
- 它会**隧道视野**——锁死一个方向,看不见别的可能(这正是 Ne 的反面,两者要配对用)。

**不该单用 Ni 的场景**:早期该探索、不该过早锁定方向时;当那个「洞见」无法被任何证据证伪时(无法证伪的不是洞见,是信仰)。

> **关键:这是镜头,不是身份。** 哪怕你自认「看不远」,也能用这套方法逼出主线;哪怕你直觉强,也要拿 bayesian-thinking 检验你的洞见,别让确信变成盲信。

### 可迁移到哪（lens 层核心）

「剥噪音、看主线」可搬到:战略判断(纷乱业务背后的真北)、长期规划、个人定位(我所有经历指向什么)、趋势预判(现象背后的方向)。

## 使用流程

1. **把所有正在做/在纠结的事列出来**(可以直接用 Ne 发散的结果)。
2. **问「这些背后,我真正想要的那一个东西是什么」**——往下追,直到追到一个不能再追的根。
3. **检验这根主线**:如果它成立,哪些事就该砍掉、哪些该加重?(主线必须能指导取舍,否则是废话)。
4. **找反证**:有没有事实和这根主线矛盾?(这一步防止 Ni 变成自我催眠)。
5. **用一句话说出方向**——说不出一句话,说明还没真正收敛。

## 输出格式

> （模仿 Ni 的认知风格：收敛、一根箭、直指本质）

```
【纷乱的事】……（罗列）
【往下追的根】这些背后我真正要的是：……
🎯【那根主线（一句话）】……
【它要求的取舍】该砍：…… / 该加重：……
【反证检查】有没有事实和它矛盾：……（防自我催眠）
```

## 示例

Input:「我又想做内容、又想做产品、又想接外包赚钱,感觉很忙但很虚。」
Output:列出三件事 → 往下追:你真正要的是「靠自己的创造力获得自由和影响力」 → 🎯主线:做一个能复利、能积累个人资产的事,而不是用时间换钱 → 取舍:外包(纯时间换钱、不复利)该砍或只作短期现金流;内容和产品要打通成一件事(内容是产品的入口) → 反证:你是否其实更享受外包的即时收入?如果是,主线要修正。一句话:停止用时间换钱,All in 一件能复利的事。
