# 外倾思维(Te)镜头:把混乱拆成可执行的结构

## 目标

用 Te 这把镜头,把一团没有头绪的事,变成有结构、有指标、能立刻动手的执行计划。

## 立场 (Stance)

Te 极擅长把模糊变可执行,但它有两个致命失效:
- 它会优化「能衡量的」而牺牲「真正重要的」——别让它把你带进虚荣指标(见 anti-vanity-metrics)。
- 它会为了效率碾过人的价值和感受——那是 F 功能(Fe/Fi)的领地,Te 看不见。

**不该单用 Te 的场景**:本质关乎意义/价值/关系的决定;早期高度不确定、过早上结构会扼杀探索的阶段。

> **关键:这是一把你可以主动拿起的镜头,不是「你是什么人」的判决。** 哪怕你天性不是 Te,也能刻意调用它来理清混乱;哪怕你 Te 很强,也要知道何时该放下它、换一把镜头。八维的威力不在用你擅长的那把,而在敢用你不擅长的那几把。

### 可迁移到哪（lens 层核心）

「把模糊拆成可执行结构」可搬到:创业运营(愿景→路线图)、个人效率(待办→优先级)、项目管理(目标→里程碑)、团队协作(目标→谁在何时做什么)。

## 使用流程

1. 把混乱**列全**——所有要做的事摊到一张清单上,先求全不求精。
2. 给每件事**定一个可衡量的目标**(没法衡量的,先逼问它到底想要什么结果)。
3. 按**影响 × 可行性**排序,逼出真正的优先级,而不是按「哪个最顺手」。
4. 把最高优先级**拆成「谁、何时、做什么」**。
5. 定**一个判断成败的指标**——然后回头用立场检查它是不是虚荣指标。

## 输出格式

> （模仿 Te 的认知风格：结构化、决断、可执行）

```
【全量清单】……
【各项可衡量目标】……
【影响 × 可行排序】……
【第一优先级的执行拆解】谁 / 何时 / 做什么
【成败指标 + 虚荣检查】……
```

## 示例

Input:「要做的事太多——公众号、小红书、做产品、找实习,全乱了。」
Output:列全四项 → 各定目标 → 打分排序(产品 9 / 实习 7 / 公众号 4 / 小红书 3)→ 砍掉后两项 → 给「产品」定本周指标「找 5 个真实用户聊需求」→ 检查:这是行动指标不是虚荣指标 ✓。
