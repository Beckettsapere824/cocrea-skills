# 第一性原理

## 这个 skill 是地板，不是天花板

读这个 skill 的你（AI），推理能力本来就足够强。这个 skill 的作用**不是给你一套模板去填**——模板只会把你的分析按到「及格的中位数」，反而拦住你本可以到达的深度。

它的作用是：**把你预激到正确的姿态，然后闪开，让你为这个具体问题自由地造结构。** 下面的「四个不可省略的动作」是地板——无论什么话题，你都必须做到这四件，掉不下去。除此之外，**怎么组织分析、用什么结构，由这个问题本身决定，不由任何固定格式决定。**

## 立场 (Stance)

第一性原理很强，但它**贵且慢**——它要求质疑每一个继承来的假设。所以不是所有事都该用它。

- **不该用的场景**：日常小决策（今天吃什么、用哪个库）。对这些用第一性原理只会让人瘫痪。惯例存在是有效率原因的，大多数时候照做就好。
- **真正值得用的场景**：当一个「大家都这么做」的前提，**一旦它错了、代价极大**时——all-in 一个方向、赌上一年时间、做不可逆的选择。

**判断信号**：当用户说「因为行业就是这样」「竞品都这么做」却说不出底层原因时，就是该用它的时刻。

## 地板：四个不可省略的动作

无论话题是什么，这四件必须做到。它们是行为，不是要填的格子。

### 1. 先去拿一手证据，别在二手推测上推理
这是最容易被跳过、也最致命的一步。当一个判断依赖「竞品/前人是怎么做的」，**不要凭印象推断他们大概怎么做——去找他们到底怎么说、怎么做的原话和硬数据。**

- 一句创始人/当事人的原话，能直接处决一个核心赌注，胜过十句你的推理。
- 有检索工具就用（web 搜索、原始文档、一手访谈、官方数据）。找不到一手证据时，**明说「这一条我没有一手证据，是推测」**，不要把推测包装成事实。
- 反例警示：分析「复制某产品」时，「我以为它的护城河是 X」和「创始人公开说护城河是 Y」之间的差距，往往就是整个判断成立与否的差距。

### 2. 把「惯例」和「事实」切开，切到不能再切
- 对每个支撑理由追问「这是可验证的事实，还是『别人都这么做』？」一直追到底。
- 标出所有「行业惯例 / 据说 / 大家都……」——这些是**继承来的假设**，是要被质疑的对象，不是地基。
- 只保留不可再分、可独立验证的事实：物理约束、用户的真实行为、成本结构、时间。

### 3. 分出「不可背离的核心」与「可以重选的部分」
继承来的设计里，混着两种东西，必须分开：
- **不可背离的**：基于物理定律 / 认知规律 / 数学结构 / 已验证事实的部分。背离它，就不再是同类东西了。
- **可重选的**：当年因为技术/资源/时间约束而被迫的选择，或纯粹的市场定位选择。这些**可以也应该重新选**。

判据：一个「不同的做法」如果让核心难题**凭空消失了** → 大概率是逃避；如果把难题**转移到你更有优势的地方** → 才是真洞察。

### 4. 说出「什么能证伪它」和「最便宜的验证」
分析不能停在「我觉得这个假设危险」。必须落到：
- 这个想法**最关键的那一个假设**是什么（一旦它错，整个想法崩）？
- **不写代码、不动用重资源**，能验证它的最小动作是什么？
- 成功信号长什么样、失败信号长什么样？

## 天花板陷阱：不要套模板

**这是 v2 最重要的改动。** 旧版本有一个固定输出格式（原结论/被剥离的假设/基本事实/重推结论/落差），实战证明它是个笼子——它让分析整齐，但把深度按死在模板的格子里。

**现在明确要求：不要套任何固定格式。** 做到上面四个地板动作后，**为这个具体问题现造它需要的结构**。

- 如果问题是「能不能自动化建知识图谱」，你可能需要把「建图」拆成信息论上异质的几层，分别判断每层可行性——这个分层是为这道题造的，别的题用不上。
- 如果问题是「该不该背离某个成熟产品的设计」，你可能需要一张「信仰 vs 约束产物 vs 市场选择」的拆解表。
- 如果问题是别的，结构也该是别的。

**自定义的、贴着问题长出来的结构，永远比套来的模板深。** 你的任务是命中四个地板动作，然后用最适合这个问题的方式把它讲透——而不是把分析削足适履塞进格子。

> **边界（与 jtbd 区分）**：first-principles 质疑的是**方案/做法的形态**——「为什么做这个、这个做法的前提成立吗」。它**不负责**分析「用户是谁、要完成什么任务」——那是 jtbd 的工作。两者同用时，first-principles 砍掉拄来的功能/惯例，jtbd 定位真实任务与真竞品。

### 可迁移到哪（lens 层核心）
第一性原理不属于物理。它的本质是「剥离继承来的假设、去拿一手证据、回到事实重推」，因此能搬到：
- **创业决策**：「这个市场需要 X」——竞品创始人真这么说过吗？回到「用户的根本痛点」重推。
- **产品取舍**：「成熟产品都有这个功能」——去查它为什么加，你的用户真需要吗？
- **职业/人生选择**：「读完研才能找到好工作」——回到「我要的能力/资源，到底靠什么获得」。

## 示例（地板级别长什么样）

> 这个示例展示的不是「一个要模仿的模板」，而是「四个地板动作 + 为问题现造结构」做到位的样子。

Input：「我要用 2026 的 AI 自动构建知识图谱，1/10 成本复制 Math Academy。」

地板级输出的关键特征（注意它没有套任何固定格式）：
- **拿一手证据（动作1）**：去搜，搜到知识图谱的实际构建者 Justin Skycak 亲口说「The answer: We handcraft it.」+ 250 小时全职手工录入权重的硬数据 → 核心赌注「AI 自动化建图」被一手证据直接证伪。**这一句原话，比任何推理都致命。**
- **切开惯例与事实（动作2）**：「Math Academy 的护城河是知识图谱」是想当然；事实是它的护城河是十几年学生数据校准出的权重 + 调度算法。
- **为问题现造结构（拆掉模板）**：把「建图」拆成信息论上异质的三层——L1 节点集（压缩问题）、L2 边的存在性（关系抽取，有结构信号可借）、L3 边的权重（隐变量估计，没有任何文本写着这个数）。**这个分层是为这道题造的。** 由此定位：真正的命门在 L3。
- **分核心与可重选（动作3）**：掌握式学习 / 间隔重复 / 知识有前置结构 = 不可背离的物理定律；手工建图 / 95 分权重精度 / 服务自驱人群 = 当年约束或市场选择，可以重选。
- **证伪与最便宜验证（动作4）**：最关键假设 = 「冷启动期纯先验图，能否好到启动数据飞轮」。最小验证 = 选 50 个知识点的单元，只用考试评分标准（mark scheme）这一个渠道生成权重，专家盲评排序合理性，量覆盖率与认可率。不写一行后端。

落差：原提案在「如何高效建造」上做到完整，却没回答「这套自动图对真实学生有没有用」——而后者是唯一重要的问题。
