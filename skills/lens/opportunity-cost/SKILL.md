# 机会成本:你放弃的,才是真代价

## 目标

让用户在做选择时,从「这件事花了我多少钱/时间」转向「我因此放弃的最好的另一个选项是什么」——真代价藏在没被选的那条路里。

## 立场 (Stance)

人天生只看**显性成本**(花了多少钱、多少时间),却对**机会成本**(放弃的最好选项)视而不见。这个盲区导致两类典型错误:

- **「免费/闲着也是闲着」陷阱**:一件事不要钱,不代表没成本。你花在它上的时间,本可以用在更有价值的事上——那才是它的真代价。
- **沉没成本伪装**:「我已经投入这么多了」是在用**过去的投入**绑架未来的选择。机会成本只看**从现在往前**:此刻继续投入,放弃的是什么?

**判断尺**:评估任何选择,不要只问「它花我多少」,要问「选它,我放弃的最好的另一个选项是什么?那个选项值多少?」

### 可迁移到哪（lens 层核心）

「真代价 = 放弃的最优选项」可搬到:
- **职业选择**:考研的成本不只是学费 + 3 年,是这 3 年你本可以工作积累的经验 + 收入。
- **时间管理**:刷 2 小时手机的成本不是 0,是这 2 小时本可以做的最有价值的事。
- **感情关系**:留在一段消耗的关系里,机会成本是你本可以遇到更合适的人/成长的时间。
- **创业**:全职创业的成本含你放弃的稳定薪水 × 时间。

## 使用流程

1. **列出选项**:把用户面临的选择和**所有可行的替代选项**列出来(很多人只看到 1-2 个,其实有更多)。
2. **戳穿显性成本幻觉**:如果用户说「这个不要钱/闲着也是闲着」,提醒他算上时间/精力的机会成本。
3. **找最优替代**:对当前倾向的选项,问「如果不选它,你能做的最好的另一件事是什么?」——这才是它的真实代价。
4. **隔离沉没成本**:如果用户在说「已经投入这么多」,明确指出那是沉没成本,不该进入「从现在往前」的计算。
5. **重新比较**:用「收益 vs 放弃的最优选项」重新评估,而不是「收益 vs 显性花费」。

## 输出格式

```
【你的选择】……
【所有可行选项】（含被忽略的）……
【你只看到的显性成本】……
【真正的机会成本】选它 = 放弃的最优选项是：……（值多少）
【沉没成本提醒】（若有）这些过去的投入不该影响现在的决定：……
【重新比较的结论】……
```

## 示例

Input:「我在纠结要不要考研,我已经准备了大半年了,放弃太可惜。」
Output:
- 你的选择:继续考研 vs 现在就业 vs 其他(考公/出国/创业)。
- 显性成本幻觉:你在算「准备了大半年」——那是沉没成本,已经花掉了,不该影响现在。
- 真正的机会成本:继续考研 = 放弃接下来 1-2 年工作积累的经验、收入、行业人脉。问自己:研究生学历带来的增量,值不值这些?
- 沉没成本提醒:「准备了大半年放弃可惜」是用过去绑架未来。正确的问法:**从今天起**,继续投入 vs 转向就业,哪个未来回报更高?
- 重新比较:如果你的目标行业不看重研究生学历,机会成本极高,值得重估。
