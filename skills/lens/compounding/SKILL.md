# 复利:微小持续 > 短期爆发

## 目标

让用户从「这次/这点有什么用」转向「持续做,长期会累积成什么」——理解复利的两个反直觉特性:**回报是非线性的(后期陡增),而中断会让积累大幅折损甚至归零**。

## 立场 (Stance)

人脑天生是**线性**的:付出 1 期待回报 1。但很多最重要的事是**复利**的——前期回报小到几乎看不见,容易让人误判「没用」而放弃,恰恰错过了后期陡增的部分。

- **复利的残酷与温柔**:残酷在于前期「看不到效果」会劝退大多数人;温柔在于只要不中断,时间会替你做大部分工作。
- **中断是复利的最大敌人**:复利依赖连续性。三天打鱼两天晒网,等于反复把指数曲线打回起点。**稳定的小投入,胜过间歇的大爆发。**
- **判断尺**:面对一件让你想放弃的事,先问「它是线性的(做一次拿一次)还是复利的(靠积累)?」如果是复利的,用「短期没效果」来判断它,本身就是错的尺子。
- **边界**:不是所有事都值得复利投入。复利放大的是「方向对的持续投入」;方向错了,持续只会让你在错的路上越走越远。先用别的 lens(如第一性原理)校准方向,再谈坚持。

### 可迁移到哪（lens 层核心）

「微小持续 → 非线性回报,中断则归零」可搬到:
- **学习**:每天读 20 页,前期无感,一年后是 7000 页的认知积累。
- **理财**:复利本来就来自这里——早开始、不中断,时间比本金重要。
- **习惯/健身**:单次健身无感,持续半年身体重塑。
- **内容创作**:前 50 篇没人看,但它们在累积你的能力和被发现的概率。
- **人际关系**:信任是复利的——长期稳定的小善意,远胜一次性的大表演。

## 使用流程

1. **判断性质**:帮用户区分他纠结的这件事是线性还是复利。复利的事不能用短期收益衡量。
2. **可视化非线性**:让用户看到「前期平、后期陡」的曲线——他现在在曲线的哪一段?是不是正好在「看不到效果」的早期?
3. **强调连续性**:指出中断的代价——复利靠不间断,问他「能不能把投入降到小到一定能坚持,而不是大到容易放弃?」
4. **校准方向**:在劝他坚持前,先确认方向是对的——复利会放大方向,方向错了别坚持。
5. **设计最小可持续动作**:帮他定一个「小到无法拒绝」的日常投入,优先保证连续性而非强度。

## 输出格式

```
【这件事的性质】线性（做一次拿一次）/ 复利（靠积累）
【你现在在曲线哪段】早期平缓（易被劝退）/ 已过拐点
【方向校准】这个方向值得复利投入吗？……
【中断的代价】为什么连续性比强度重要：……
【最小可持续动作】小到一定能坚持的日常投入：……
```

## 示例

Input:「我想学英语,但每天背单词太枯燥了,背了两周感觉没任何提升,想放弃。」
Output:
- 性质:语言学习是典型复利——词汇/语感靠长期积累,两周看不到提升是正常的早期平缓段。
- 你在曲线哪段:最早期。这时用「有没有提升」判断,等于在指数曲线刚起步时说它没用。
- 方向校准:你确实需要英语吗?如果是(留学/工作/兴趣),方向对,值得复利投入。
- 中断代价:背两周停一周再重来,等于反复回到起点。连续性比每天背多少更重要。
- 最小可持续动作:把目标从「每天背 50 个」降到「每天背 5 个 + 不断签」——小到无法拒绝,先保证一年不断,而不是两周冲刺后放弃。
