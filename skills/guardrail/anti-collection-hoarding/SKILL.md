# 反收藏囤积:收藏 ≠ 学会

## 目标

在用户疯狂收藏/囤积学习资料却从不消化时叫醒他,戳破「保存=拥有=学会」的错觉,把行为从「囤积」转回「消化少量并真正用上」。

## 立场 (Stance)

收藏一篇干货、买一门课的瞬间,大脑会分泌一种**虚假的满足感**——仿佛知识已经进了脑子。但收藏夹里躺着的内容,和你的认知没有半点关系。**拥有信息的入口,不等于拥有知识。**

- **囤积的心理机制**:收藏是「低成本、即时满足」的动作,它用「我在为学习做准备」的姿态,替代了「真正去学」这件高成本、费力的事。本质和拖延一样。
- **囤积的隐性伤害**:庞大的「待学清单」会持续制造焦虑(总有学不完的东西),却从不转化为能力。你越囤越焦虑,越焦虑越想囤(囤积带来短暂安慰)——形成循环。
- **判断尺**:问「我收藏的东西里,有多少真正读完并用上了?」如果收藏量远大于消化量,你在囤积,不是学习。
- **稀缺性原则**:真正稀缺的从来不是信息(信息无限且免费),而是**你的注意力和消化时间**。该被珍惜和管理的是后者,不是前者。

**这不是反对保存任何资料,而是反对用『保存的动作』冒充『学习的结果』。**

## 使用流程

1. **照镜子**:让用户估一下「收藏/囤积总量 vs 真正消化的量」——这个落差通常会让他自己警醒。
2. **不羞辱**:指出囤积是极普遍的、被设计出来的行为(平台鼓励你收藏),不是他自制力差。
3. **戳破准备幻觉**:点明「收藏=为学习做准备」是错觉,准备本身不产生任何学习。
4. **清单破产**:建议对积压的收藏夹做一次「破产清算」——大部分根本不会看,坦然清掉,只留极少数真正要用的。减轻虚假负担。
5. **改规则**:确立「消化 > 收藏」的新规则——比如「想收藏一篇,先花 10 分钟读完并写一句它对我有什么用,否则不存」。让保存重新变得有成本。
6. **少而深**:引导他选 1-2 个真正相关的深入消化,而不是收藏 100 个浅尝。

## 输出格式

```
【你的囤积现状】收藏/囤积量 vs 真正消化量：……
【囤积在替代的真问题】你其实在逃避的高成本动作：真正去学
【准备幻觉】收藏 ≠ 准备 ≠ 学会
【收藏夹破产建议】坦然清掉不会看的，只留：……
【新规则】让保存重新有成本：……
【现在就消化的 1-2 个】……
```

## 示例

Input:「我微信收藏夹存了三四百篇学习干货,B 站收藏了几十门课,但基本没看过,看着又焦虑又舍不得删。」
Output:
- 囤积现状:存了三四百篇 + 几十门课,消化接近 0。落差本身说明:这是囤积,不是学习。
- 在替代的真问题:收藏是低成本动作,它让你回避了「真正坐下来学一门课」这件费力的事。
- 准备幻觉:存下来那一刻的「以后能学」是错觉,这些内容从未进入你的认知。
- 破产建议:坦然承认 90% 不会看,清掉。留不下来的焦虑,正是它在白白消耗你。
- 新规则:以后想收藏,先读完 + 写一句「它对我现在有什么用」,写不出就不存。
- 现在消化:从几十门课里挑 1 门最相关的,这周看完并实操一次,胜过再囤 100 篇。
