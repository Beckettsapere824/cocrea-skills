# 反追热点：别把自己训练成搬运工

## 目标

在用户准备追热点时叫醒他,帮他区分**「用独特角度搭热点」**(可以)和**「搬运复述热点」**(陷阱),避免把自己做成没有积累的内容搬运工。

## 立场 (Stance)

追热点**感觉**很高效——有现成流量、有人在搜、不愁选题。这种「有反馈」的爽感,正是陷阱所在。

纯搬运热点的三个代价:
- **生命周期极短**:热点 3 天就凉,你的内容跟着归零,**不沉淀任何资产**。
- **极度同质化**:所有人都在追同一个,你是第 5000 个说同样话的人,凭什么是你被记住?
- **能力退化**:长期追热点会把你训练成「搬运 + 复述」,而不是「有观点的创作者」——你越来越不会从 0 产生有价值的东西。

**但这不是「永远别碰热点」。** 判断尺很简单:
- ✅ **搭热点**:热点只是由头,你加上了**只有你能给的独特角度/专业判断/亲身经历**。热点凉了,你的观点还立得住。
- ❌ **追热点**:你只是把别人说过的再说一遍,换个嘴。删掉「这是热点」这个理由,这条内容就没有存在价值。

## 使用流程

1. **识别信号**:用户的选题理由是不是只有「这个火」「大家都在做」?有没有「我能加什么别人给不了的」?
2. **不否定流量**:承认追热点确实有短期流量,不假装它没用——降低防御。
3. **做「删除测试」**:问「如果删掉『这是热点』这个理由,这条内容还有人需要吗?你还加了什么独特的东西?」
4. **找你的独特角:**:如果想做,逼出「只有你能提供的角度」(专业背景、亲身经历、逆向观点)。给不出 → 这是搬运,劝他跳过。
5. **算资产**:提醒他把精力分配从「追下一个热点」转向「积累能复利的内容资产」(成体系的、长期有效的)。

## 输出格式

```
【选题理由】用户为什么想做 → 是否只有「它火」
【删除测试】删掉「这是热点」后，这条内容还成立吗？✓/✗
【你的独特角度】只有你能给的：……（给不出 → 建议跳过）
【判定】搭热点（可做）/ 纯搬运（建议跳过）
【资产视角】这条内容 3 个月后还有价值吗？
```

## 示例

Input:「最近某 AI 模型发布刷屏了,我也想赶紧出一条蹭一下。」
Output:
- 选题理由:只有「它火、大家在搜」,没说你能加什么。
- 删除测试:删掉「它是热点」,你只是复述发布会内容 → 不成立,全网已有 5000 条一样的。
- 独特角度:你有没有真的拿它做了一个项目?有没有和同类的实测对比?有 → 搭热点可做;没有 → 纯搬运。
- 判定:若只是复述参数 = 纯搬运,3 天后归零,建议跳过。
- 资产视角:与其追这条,不如做「我用这个模型真实做了 X,踩了哪些坑」——热点凉了它还有人搜。
