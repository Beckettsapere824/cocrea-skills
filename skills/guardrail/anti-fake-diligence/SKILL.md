# 反低效勤奋:别用辛苦冒充学到

## 目标

在用户用「努力的形式」(抄笔记、熬时长、反复划线)冒充「学习的结果」时叫醒他,区分**感动自己的勤奋**和**真正费脑的学习**,把衡量标准从「我多辛苦」换成「我多学到」。

## 立场 (Stance)

低效勤奋是最隐蔽的陷阱,因为它**看起来无可指责**——你确实坐了一整天,确实很累。但累 ≠ 学到。

- **低效勤奋的本质**:用「体力上的辛苦」和「形式上的忙碌」,逃避「认知上的吃力」。抄一遍漂亮笔记、把书划满线、在图书馆坐 10 小时刷手机——这些都有「我在努力」的安慰感,却几乎不触发真正的思考。
- **为什么人沉迷于此**:真正的学习(主动回忆、讲清楚、解难题)是**费脑且让人不适**的,大脑本能回避。而抄笔记、重读是**低认知负荷**的,做起来舒服。于是人用舒服的勤奋,替代了痛苦的有效学习。
- **自我感动的危险**:「我都这么努力了成绩还不好」会让你归因为「我笨/运气差」,而真正的原因是「努力用错了方式」。它既消耗你,又误导你。
- **判断尺**:问「我刚才这一小时,大脑真正吃力地思考/提取了吗?还是只是手在动、眼在扫、人在坐?」

**这不是叫你别努力,而是叫你把努力放在『费脑』的地方,而不是『费时间/费体力』的地方。有效的学习常常时长更短,但更累脑。**

## 使用流程

1. **识别形式感勤奋**:用户的「努力」是不是集中在抄笔记、重读、划线、堆时长这类低认知负荷动作上?
2. **不否定辛苦**:承认他是真的付出了时间和体力,不说他懒——他不是懒,是方向错了。降低防御。
3. **区分两种累**:点出「体力/时间的累」和「认知的累」不同,只有后者对应真正的学习。问他今天「脑子真正吃力」的时间有多少。
4. **戳破自我感动**:如果出现「我这么努力还……」的归因,明确指出问题不在努力量,在努力的方式。
5. **换标准**:把「今天学了几小时」换成「今天我能合上书讲清/做出几个之前不会的东西」——用产出而非投入衡量。
6. **转向费脑动作**:引导他把时间从抄笔记/重读,转到主动回忆、费曼讲解、做题这类真正费脑的事(配合 active-recall / feynman-technique)。

## 输出格式

```
【你的努力形式】低认知负荷（抄/读/划/坐时长）/ 高认知负荷（回忆/讲解/解题）
【你逃避的真问题】费脑的、让人不适的思考：……
【两种累的区分】今天「脑子吃力」的时间 vs「人在坐」的时间：……
【自我感动提醒】（若有）问题不在努力量，在方式：……
【新标准】用产出衡量：今天能讲清/做出几个之前不会的？……
【转向费脑动作】……
```

## 示例

Input:「我每天在图书馆待 10 小时,笔记抄得工工整整,可月考还是中下游,我是不是真的不适合读书?」
Output:
- 努力形式:10 小时 + 工整笔记 = 典型低认知负荷的形式勤奋。抄笔记几乎不触发思考。
- 逃避的真问题:做题、合上书自测这些费脑又容易暴露「我不会」的事,被「抄笔记」的安全感替代了。
- 两种累:你累的是体力(久坐)和手(抄写),不是脑子。真正学到的时间可能远不到 10 小时。
- 自我感动提醒:「这么努力还中下游」不是你不适合读书,是你的努力 90% 花在了不产生学习的动作上。
- 新标准:别再记「今天待了几小时」,改记「今天合上书能独立做对几道之前不会的题」。
- 转向:把抄笔记的时间砍掉一半,换成「合上书默写知识点 + 做题 + 错题重做」。时长可能更短,但你会第一次觉得「脑子是真的累」——那才是学到了。
