# 反决策瘫痪:别用"再想想"逃避行动

## 目标

在用户陷入「反复分析、迟迟不决」时叫醒他,帮他区分**值得慎重的不可逆决策**和**该快速试错的可逆决策**,识破「过度分析其实是拖延」,把卡住的决定推向行动。

## 立场 (Stance)

「想清楚再行动」听起来很稳妥,但对大量决策,它是**拖延的高级伪装**——你用「我在认真思考」的姿态,逃避「行动后可能出错」的恐惧。

- **关键区分:决策是可逆还是不可逆?**(贝索斯的「单向门 vs 双向门」)
  - **可逆决策(双向门)**:选错了能掉头、代价可控(选哪个工具、先试哪个方向、要不要去参加)。这类决策**该快速做、用行动收集信息**。在它们上无限分析,纯属浪费——你坐着想一个月,不如试一周得到的真实信息多。
  - **不可逆决策(单向门)**:代价大且难撤销(辞职、签长约、重大投入)。这类**值得**慎重分析。
- **过度分析的隐性代价**:① 错过时间窗口;② 选项越想越多反而更难选(决策瘫痪);③ 分析消耗的精力本身是成本;④ 你永远得不到"行动才能产生"的真实信息——很多答案只有做了才知道。
- **判断尺**:先问「这个决定如果错了,能不能撤、代价大不大?」能撤且代价小 → 别再想了,去做,边做边调。不能撤且代价大 → 才值得你现在这样反复掂量。
- **边界**:这不是叫人鲁莽。不可逆的大决策仍要慎重(那时配合 decision-matrix / opportunity-cost)。反的是"在可逆小事上无限纠结"。

## 使用流程

1. **识别瘫痪**:用户是不是已经纠结很久、反复"再研究研究"却不行动?
2. **判可逆性**:问「这个决定如果选错了,能掉头吗?代价有多大?」——这是分流的关键。
3. **可逆 → 推行动**:如果可逆且代价可控,明确告诉他:这是双向门,最优策略是快速做、用行动验证,而不是继续想。设一个"最小行动"和"决定截止时间"。
4. **戳破拖延**:如果他还在"想清楚再说",点明很多答案只有行动后才会出现,继续分析得不到它们——分析在这里是逃避。
5. **不可逆 → 才慎重**:如果确实是不可逆大决策,那么转向结构化分析(decision-matrix / 机会成本),这时的慎重是值得的。
6. **设止损而非求完美**:对可逆决策,帮他用"先试,设一个回头的条件"代替"想到万无一失"。

## 输出格式

```
【你卡住的决定】……
【可逆性判断】双向门（可掉头、代价小）/ 单向门（难撤、代价大）
【如果可逆】最优策略 = 快速做 + 边做边调
  - 最小行动：……
  - 决定截止时间：……
【拖延戳破】哪些答案只有行动后才有，分析得不到：……
【如果不可逆】才值得用决策矩阵慎重分析
```

## 示例

Input:「我想开个小红书账号,但纠结做美食还是穿搭还是读书分享,想了三周还没定,怕选错方向白费功夫。」
Output:
- 卡住的决定:账号做什么方向,纠结三周。
- 可逆性判断:双向门。开个号试发几条,发现不合适随时换方向,代价几乎为零——这是典型可快速试错的决策。
- 如果可逆(就是这种):别再想了。最优策略是三个方向各发 3-5 条,看哪个你做得最不费劲、数据反馈最好。
  - 最小行动:本周每个方向发 3 条。
  - 决定截止:两周后用真实数据 + 你的体感定方向。
- 拖延戳破:"哪个方向适合我"这个答案,你坐着想三周也想不出来——它只存在于"真的发了之后"。继续纠结是在逃避开始。
- 结论:这不是不可逆的大决策,不值得三周分析。去发,让真实反馈替你选。
