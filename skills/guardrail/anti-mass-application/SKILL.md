# 反海投:别用投递数量逃避定位问题

## 目标

在用户准备/正在海投时叫醒他,指出海投往往是**用「我很努力在找」的姿态,逃避「我定位不清、不知道自己适合什么」的真问题**,把精力从「投更多」转向「投得准」。

## 立场 (Stance)

海投**感觉**很努力——投了 200 份,你觉得自己尽力了。这种勤奋感正是陷阱:它让你回避了那个更难、更痛的问题——**「我到底适合什么、凭什么被选中」**。

- **海投的真实代价**:
  - **转化率极低**:不针对岗位的简历,HR 一眼看出「群发」,直接跳过。投 200 份不如投 20 份针对性的。
  - **摧毁信心**:200 份石沉大海,你会归因为「我不行」,其实是「我没说清我行在哪」。
  - **掩盖真问题**:只要还在海投,你就不用面对「我定位不清」这件事。它是拖延的高级形式。
- **判断尺**:如果你的求职策略是「投得够多总有一个」,而不是「我清楚自己适合 X,针对性地投 X」,你是在用数量逃避定位。

**这不是说投递数量不重要,而是说:在定位清晰之前,加大投递量只会放大失败。先解决「投给谁、凭什么」,再谈量。**

## 使用流程

1. **识别信号**:用户是不是把困境归结为「投得不够多」?有没有「广撒网」「多投总没错」式表述?
2. **不否定努力**:承认找工作的焦虑和投递的辛苦,不假装海投者偷懒——降低防御。
3. **算真账**:对比「投 200 份泛简历 vs 投 20 份针对性简历」的真实转化,戳破「数量=机会」的错觉。
4. **挖真问题**:逼出「你清楚自己适合什么岗位吗?能说出凭什么是你吗?」——往往这里是空的,这才是病根。
5. **转向**:把精力从「投更多」转到先做定位(配合 `positioning-statement`)和针对性改写(配合 `resume-rewrite`),再小批量精准投。

## 输出格式

```
【你的海投信号】投递量/广撒网式表述：……
【海投在帮你逃避的真问题】你其实还没想清的是：……
【真账】泛投 200 vs 精投 20 的转化对比：……
【该先解决的】定位是否清晰？能说出凭什么是你吗？✓/✗
【转向建议】先做 X，再小批量精准投：……
```

## 示例

Input:「我都投了快 300 份简历了,基本没回音,是不是要再多投点别的公司?」
Output:
- 海投信号:300 份 + 「再多投点」——典型用数量解决问题。
- 在逃避的真问题:你能说清自己适合哪一类岗位、凭什么被选吗?300 份大概率是同一份简历群发,说明定位是空的。
- 真账:300 份泛简历的回复率,通常远低于 20 份「针对岗位重写 + 定位清晰」的简历。不是投少了,是每一份都没说服力。
- 该先解决:停下海投。先用定位工具想清「我适合什么、凭什么」,再针对性改简历。
- 转向:先锁定 2-3 类真正匹配的岗位,各精修一版简历,小批量投,看回复率再调整——而不是把同一份再发给第 301 家。
