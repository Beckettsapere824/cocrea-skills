# 反沉没成本:过去的投入,不该绑架未来

## 目标

在用户因「已经投入太多、放弃可惜」而准备继续一个错误选择时叫醒他,把决策依据从「我过去花了多少」拉回到「从现在往前,继续 vs 放弃,哪个未来回报更高」。

## 立场 (Stance)

「已经投入这么多了,不能白费」——这句话听起来理性,其实是人类最普遍的决策陷阱之一(沉没成本谬误)。

- **核心事实**:已经付出且**无论如何都收不回**的成本(时间、金钱、感情),是**沉没**的。它已经发生,无论你接下来怎么选都不会改变。所以它**不该**进入「现在该怎么做」的计算。
- **正确的问法**:不是「我已经花了多少」,而是「**从今天起**,继续投入会带来什么、放弃会带来什么,哪个更好」。决策只看未来,不看过去。
- **为什么难**:放弃意味着承认「之前的投入错了」,这在情感上很痛。于是人继续投入,用未来的更多损失,逃避「承认错误」的痛——结果越陷越深(这正是赌徒和烂尾项目的逻辑)。
- **关键区分**:要分清**沉没成本**(收不回的过去投入)和**仍在产生价值的既有资产**(过去投入但现在/未来还能持续受益的)。反的是前者,不是后者。不是"凡是过去投入的都该无视",而是"收不回且不再产生价值的,别让它绑架你"。
- **判断尺**:假装你是个**刚空降的局外人**,没有任何历史包袱,只看「从现在往前」的利弊——你会怎么选?那才是理性的选择。

## 使用流程

1. **识别信号**:用户的理由里有没有「都已经……了」「不能白费」「来都来了」「舍不得之前的投入」?
2. **共情痛感**:承认放弃很难,因为它意味着面对「之前投入打了水漂」——这个痛是真实的,不羞辱。
3. **分离沉没与资产**:帮他区分「收不回的沉没成本」和「还在产生价值的资产」。只有前者要被排除。
4. **空降局外人测试**:问「如果你是今天刚接手这件事的人,没有任何历史包袱,只看未来利弊,你会继续吗?」
5. **重算未来账**:仅基于「从现在往前」的成本和收益重新评估,过去的投入完全不计入。
6. **接住情绪**:如果结论是放弃,帮他把"承认错误"重构成"及时止损是更高级的理性",减轻心理负担。

## 输出格式

```
【你的沉没成本理由】"已经……了/不能白费"：……
【哪些是真沉没成本】收不回、不再产生价值的：……
【哪些是仍在产生价值的资产】（这些可以纳入考虑）：……
【空降局外人测试】今天刚接手、没有包袱的你，会继续吗？……
【只看未来的重算】从现在往前，继续 vs 放弃：……
【结论】……（若是止损，这是理性不是失败）
```

## 示例

Input:「我学钢琴学了 5 年但越来越痛苦,真的不喜欢,可投入这么多年和这么多学费,放弃太可惜了。」
Output:
- 沉没成本理由:「学了 5 年、花了这么多学费,放弃可惜」——典型沉没成本绑架。
- 真沉没成本:已经付的学费、已经花的 5 年——收不回,无论你弹不弹琴都不会回来。不该影响现在。
- 仍在产生价值的资产:你已经习得的乐理、手感、对音乐的理解——这些不会消失,即使停课也还在。所以"放弃"并不等于"5 年归零"。
- 空降测试:如果你今天才发现自己不喜欢钢琴、且还没投入过,你会从今天开始每周痛苦地练琴吗?大概不会。
- 只看未来:继续 = 持续的痛苦 + 时间;放弃 = 释放出时间精力做你真正喜欢的事。已习得的能力还在。
- 结论:停下不是浪费了 5 年,是不再用第 6、7 年继续偿还一个错误。及时止损是理性。
