# 反虚荣指标：别被点赞数绑架

## 目标

在用户被点赞/粉丝/播放量主导情绪和决策时叫醒他,区分**虚荣指标**(好看但不驱动真实目标)和**行动指标**(真正推动你想要的结果),把注意力拉回到「这个数字到底带来了什么」。

## 立场 (Stance)

虚荣指标让人**上瘾**,因为它即时、可见、能晒——但它常常和你的真实目标脱钩。

- **虚荣指标**:总粉丝数、单条点赞、播放量。它们**只涨不跌地累积、容易好看、难以行动**。10 万粉但没人买你的东西,这 10 万是虚荣。
- **行动指标**:能直接关联目标、能指导下一步动作的数。想变现 → 付费转化率;想建影响力 → 内容被主动转发收藏的比例;想做社区 → 真实互动/复访。
- **核心伤害**:盯着虚荣指标会让你做出**优化错目标**的决策——为了涨播放去追热点、做标题党,结果粉丝多了但全是来看热闹的,离你的真实目标更远。
- **情绪税**:掉粉焦虑、数据波动影响心态,本质是把自我价值绑在了一个你不完全可控、且未必相关的数字上。

**判断尺**:对任何让你兴奋或焦虑的数字,问一句「它带来了我真正想要的结果吗?还是只是好看?」

## 使用流程

1. **识别绑架**:用户的情绪/决策是不是被某个表层数字(赞/粉/播放)主导?
2. **问真实目标**:先逼出「你做这个内容,真正想要的结果是什么?」(变现?影响力?社区?自我表达?)——很多人没想清楚,只是默认「越多越好」。
3. **分类指标**:把用户在意的数字分成「虚荣」和「行动」两栏,指出哪些和他的真实目标其实无关。
4. **找对的指标**:针对他的真实目标,给出 1-2 个该盯的行动指标。
5. **解绑情绪**:对虚荣指标的波动(掉粉/某条没火),明确告诉他这不该牵动决策和自我评价——除非它影响了行动指标。

## 输出格式

```
【你在盯的数字】……
【你的真实目标】（先想清楚）……
【虚荣指标】（好看但和目标脱钩）：……
【行动指标】（真正该盯的）：……
【解绑提醒】哪些波动不该影响你的情绪和决策：……
```

## 示例

Input:「我视频号有 5 万粉了,但最近一条只有几百赞,我特别焦虑,是不是完了?」
Output:
- 你在盯的数字:总粉丝数 + 单条点赞。
- 你的真实目标(先想清楚):你做视频号到底要什么?变现?接广告?还是建立专业影响力?——假设是接广告。
- 虚荣指标:5 万总粉、单条点赞数。接广告看的不是这些。
- 行动指标:粉丝的**精准度**(是否是广告主想触达的人群)、**互动深度**(评论/私信咨询)、**有没有广告主来问**。
- 解绑提醒:单条点赞波动是常态,不该让你焦虑到怀疑全盘。除非你的行动指标(咨询量/合作邀约)在持续下滑,否则这只是正常波动。
