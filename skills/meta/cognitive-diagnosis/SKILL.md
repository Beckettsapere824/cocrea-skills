# 八维认知诊断入口

## 目标

帮一个**陷在某种思维模式里而不自知**的人跳出来——先看清他在过度用哪一维、缺哪一维，再把他缺的那把镜头递过去。

这是 `cognitive-functions-360` 包的**被动入口**。八维有两种用法，这是第二种：

- **主动请求**：用户点名某一把（「用 Ne 帮我头脑风暴」「用 Fi 看看这是不是我要的」）→ 直接调那把镜头，不需要诊断。
- **被动诊断**（本 skill）：用户**没点名**、但话里明显透出卡点 → 先诊断，再递缺失的那把。

## 立场 (Stance)

**核心原则：永远递「缺的那把」，绝不递「已经淹在里面的那把」。**
一个一直空谈的人，不需要更多思考框架，他需要被推去行动（Se）。给他再多分析工具，只会加深他的循环。诊断的全部价值，就在于**给他没用的那个视角**，而不是顺着他的惯性。

**失效模式 / 不该用的场景：**
- **用户已点名某功能** → 别越俎代庖去"诊断"，照他说的调。
- **用户没卡住，只是在正常陈述** → 别硬给人贴"你陷在 X 维"的标签，那是冒犯，也是过度干预。诊断只在卡点**明显**时出手。
- **别一次甩 8 把** → 那是决策瘫痪（见 anti-analysis-paralysis）。诊断的产物是 **1-2 把**精准的缺失镜头，不是全套体检。
- **绝不贴人格标签** → 不说「你是 INTJ / 你是 T 人」。只说「你这段话在过度用 X、缺 Y」，对事不对人。

## 诊断表（症状 → 过度用 → 缺 → 递哪把）

| 观察到的症状 | 过度依赖 | 缺 | 递给他 |
| :--- | :--- | :--- | :--- |
| 一直计划/空谈，迟迟不动手 | 思考(Ti/Ni) | 行动 | **se-action** |
| 冲动行事、不想后果、反复踩同坑 | Se | 经验/远见 | **si-precedent** / ni-convergence |
| 困在一条路、钻牛角尖、"只能这样" | Ti/Si | 可能性 | **ne-possibility** |
| 想法太多、什么都浅尝、无法收敛 | Ne | 主线 | **ni-convergence** / te-structuring |
| 纯算利弊、忽略人和关系 | Te | 他人 | **fe-harmony** |
| 达成目标却空虚、活在别人期待里 | Te(外部指标) | 本心 | **fi-authenticity** |
| 过度在意别人怎么想、丢了自己 | Fe | 自我价值 | **fi-authenticity** |
| 用"忠于自己"当逃避困难的借口 | Fi | 结构/行动 | **te-structuring** / se-action |
| 满嘴大词、逻辑含糊、自我感动 | 直觉/情感失检 | 逻辑 | **ti-coherence** |
| 死守旧经验、抗拒新东西 | Si | 可能性 | **ne-possibility** |
| 沉迷宏大愿景、无视矛盾的现实 | Ni | 现实/逻辑 | **se-action** / ti-coherence |

> 这些"过度↔缺失"的配对，正是荣格功能的对位关系——你最不顺手的那把，往往就是此刻最该用的那把。

## 使用流程

1. **先判断要不要出手**——用户卡住了吗？还是只是在正常陈述？没明显卡点，不诊断。
2. **听出他在过度用哪一维**——他这段话反复在做的那个动作（一直分析？一直发散？只算账？）。
3. **对照诊断表，定位他缺的那把**——他惯性的反面。
4. **只递 1-2 把缺失镜头**——并用一句话点破："你这段话一直在 X，但可能缺了 Y 这个角度。"
5. **用那把镜头跑一遍**——调用对应的 lens skill，给出那个视角下的看法。
6. **不替他下结论**——递视角，不替他做决定。

## 输出格式

```
【我观察到的模式】你这段话一直在……（指出过度用的那一维，对事不对人）
【可能缺的视角】……（缺的那一维 + 为什么是它）
🔄【换这把镜头看】（调用缺失的 lens，给出该视角下的重新审视）
```

## 示例

Input（用户长篇）:「我研究了三个月的商业模式，竞品分析做了 20 页，财务模型改了八版，市场调研也看了一堆报告，但我还是觉得没准备好，总觉得还有风险没排掉，可能再补几个数据就……」

Output:
- 【模式】你这三个月一直在**分析和准备**——思考维度已经拉满了。
- 【缺的视角】你缺的不是更多数据，是**行动**（Se）。"还有风险没排掉"是一个永远满足不了的条件——它在保护你不必下场。
- 🔄【换 se-action 看】停。你已经想得够多了。眼前真实存在的是：你有一个想验证的模式、有时间、有触达第一批用户的渠道。现在这一秒能做的最小一步是——别再补第九版模型，去找 3 个真实潜在用户聊 20 分钟，让现实告诉你哪个风险是真的。完美的准备永远在路上，第一个真实信号只能靠现在去问。
