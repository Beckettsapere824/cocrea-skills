# CoCrea Skill 检索助手

> 与 `cocrea-skill-creator` 配对：finder 负责「找到该用的」，creator 负责「没有就造」。
> 两者构成 CoCrea 的杠杆对——找不到 → 造出来 → 回流入库，形成 contribution loop。

## 目标

根据用户**当前的真实问题**，从库里精准找出该用的 skill / 包，并做**跨学科推荐**——这是 finder 区别于普通搜索的核心：把一个领域的思维模型，推荐给另一个领域的人。

数据源：仓库根 `CATALOG.json`（由 `generate-catalog.mjs` 自动生成，机器可读）。

## 立场 (Stance)

普通搜索做**关键词匹配**——用户问「创业」，只返回标了「创业」的 skill。**这恰恰是我们要超越的。**

CoCrea 的护城河是**跨学科迁移**。finder 的价值，是把物理学的「第一性原理」推荐给一个做创业的人，把经济学的「优化模型」推荐给一个在做时间管理的人。这种推荐用户**自己想不到**，正是它不可替代的原因。

- **不做**：只按学科标签返回同领域 skill（那是普通搜索，没有我们的价值）。
- **要做**：读懂用户问题的**底层结构**，跨学科匹配 `transfer` 字段，给出「你可能没想到，但其实最适合你的」推荐。
- **边界**：finder 只推荐，不替用户判断该不该做某件事——那是各 skill 自己的立场层负责的。

## 使用流程

1. **读取 catalog**：
   - 若本地已订阅/clone：直接读仓库根 `CATALOG.json`。
   - 若未 clone：从 `https://raw.githubusercontent.com/Beckettsapere824/cocrea-skills/main/CATALOG.json` 拉取。
2. **理解问题的底层结构**：不要停在用户用的词上。问自己「他真正要解决的是哪一类问题？」（验证假设？看清需求？避免某个错误？砍范围？）
3. **三层匹配**（按 CoCrea 飞轮顺序推荐）：
   - 他需要**先看懂**什么概念吗？→ 匹配 `layer: lens`
   - 他需要**动手做**什么吗？→ 匹配 `layer: craft`
   - 他可能**正在犯**什么错吗？→ 匹配 `layer: guardrail`（这条最该主动提，用户往往意识不到）
4. **跨学科迁移推荐（核心）**：扫描所有 lens 的 `transfer` 字段，找出「源领域不是用户当前领域，但 transfer 覆盖了他的处境」的 skill，作为「你可能没想到」的推荐重点说明。
5. **优先推包**：如果匹配到的多个 skill 同属一个 package，直接推荐整个包（带推荐顺序），而不是零散 skill——包已经把工作流串好了。
6. **找不到就转 creator**：如果库里确实没有匹配的，明确告诉用户「目前没有现成的，要不要用 `cocrea-skill-creator` 造一个?」——这是 contribution loop 的入口。

## 输出格式

```
【你的问题，我的理解】一句话点出底层结构

【直接匹配】
  - <skill/包名>（<层>）— 为什么适合你

【你可能没想到（跨学科推荐）】
  - <skill名>（来自<源学科>）— 它本来用于<原领域>，但能迁移到你的<处境>

【提醒你可能在犯的错（护栏）】
  - <guardrail skill> — 为什么现在该看它

【没有现成的？】
  → 用 cocrea-skill-creator 造一个，造完回流入库帮到下一个人
```

## 示例

Input: 「我想做个独立游戏，已经在设计技能树和成就系统了，但还没人玩过。」
Output:
- 你的问题，我的理解：你在为「还没被验证的需求」投入复杂度——这是结构问题，不是游戏设计问题。
- 直接匹配：`founder-anti-patterns` 包（跨三层）——它正好处理「想法很大但没验证」。
- 你可能没想到：`first-principles`（来自物理）——你默认「好游戏要有技能树+成就」，但这是行业惯例还是你的玩家真需要？回到事实重推。
- 提醒你可能在犯的错：`anti-over-engineering`（护栏）——你在没有一个玩家时设计成就系统，这是在用「做系统」逃避「让人来玩」的验证。
- 建议：先用 `mvp-scoping` 砍到「一个能让 10 个人试玩核心循环的最小 demo」。

## 红线

- 不退化为关键词匹配——跨学科迁移是存在意义。
- guardrail 推荐要主动（用户意识不到自己在犯错）。
- 找不到不硬凑——诚实转 creator。
